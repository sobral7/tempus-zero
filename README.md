# TEMPUS ZERO — O Segundo Eterno

> Alguns instantes merecem ser eternos.

## Sobre o projeto

O TEMPUS ZERO é um projeto conceitual de experiência digital inspirado na relação entre o tempo, a memória e a percepção humana.

A proposta combina uma identidade visual minimalista e sofisticada com elementos interativos, apresentando uma coleção fictícia de relógios conceituais em uma landing page.

O projeto foi desenvolvido para explorar a construção de interfaces web, a experiência do usuário e a interação entre design e tecnologia.

## Funcionalidades

- **Landing page:** apresentação do conceito e da identidade do TEMPUS ZERO.
- **Navegação por seções:** acesso às áreas de experiência, produto, manifesto e coleção.
- **Experiência interativa:** desafio para tentar capturar exatamente um segundo.
- **Relógio ilustrativo:** ponteiros animados que representam a passagem do tempo.
- **Detalhes dos produtos:** janela interativa com informações sobre as peças conceituais.
- **Formulário demonstrativo:** permite preencher campos e visualizar uma mensagem de confirmação sem enviar ou armazenar os dados.
- **Menu responsivo:** navegação adaptada a diferentes tamanhos de tela.

## Tecnologias utilizadas

- HTML5 — estrutura e semântica da página.
- CSS3 — identidade visual, layout, animações e responsividade.
- JavaScript — interações, navegação e funcionalidades dinâmicas.
- Git e GitHub — controle de versão e gerenciamento do código.

## Como executar o projeto

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra a pasta `tempus-zero` no Visual Studio Code.
3. Abra o arquivo `index.html` com a extensão Live Server, caso esteja instalada.
4. Acesse o endereço local disponibilizado pelo Live Server no navegador.

Também é possível abrir o arquivo `index.html` diretamente no navegador para visualizar a página.

## Experiência do usuário

A interface utiliza uma identidade visual baseada em tons escuros e dourados, com tipografia expressiva e elementos minimalistas.

A navegação foi pensada para funcionar em computadores e dispositivos móveis, mantendo o foco na apresentação do conceito e nas interações da experiência.

## Observação sobre o formulário

O formulário é exclusivamente demonstrativo. Os dados preenchidos não são enviados a um servidor nem armazenados pelo projeto. A mensagem de confirmação representa apenas uma interação local da interface.
